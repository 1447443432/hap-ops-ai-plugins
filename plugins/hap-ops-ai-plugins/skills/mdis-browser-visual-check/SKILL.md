# MDIS 浏览器视觉自测

1. 阅读项目及受影响模块的 AGENTS.md；先确认开发地址、服务状态及测试范围。使用 Orca 内置浏览器时先读取 orca-cli 技能和对应浏览器参考文档。
2. 在实际页面检查受影响的日间、官方日间、夜间主题；覆盖桌面和窄屏，观察文字、边框、状态、弹窗、下拉、滚动、焦点与溢出。Grafana 嵌入额外检查 kiosk、主题、筛选及跨域限制。
3. 以实际截图和可复现操作定位问题，不把静态检查或构建成功当成视觉验收。修复后在同一视口重测，记录未覆盖页面及真实外部环境限制。避免修改业务数据；测试用写操作须有明确授权和清理方案。
4. 不输出凭据或用户数据，不推送 Git。根据真实使用中发现的问题更新本 skill，记录具体经验，避免加入未经验证的假设。

表格分页区和侧栏底部的分割线可能来自共用 LESS 变量，而不是表格行自身的边框。排查亮线时分别检查这两处的实际计算颜色，并对照深浅主题截图。
