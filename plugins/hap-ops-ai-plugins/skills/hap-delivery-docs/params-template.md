## 四、缺省值（留空时采用，对应标准版示例拓扑）

VIP 192.168.1.20；Nginx .11/.12；K8s .21/.22/.23；DB .31/.32/.33（MGR+Router 6446）；
Redis .41/.42/.43；中间件 .51/.52/.53/.54；HDP/Flink .61/.62；域名 hap.domain.com:443。（标准版 17 节点拓扑）

> 专业版（并发1000+）：各组件**独立部署**共 **26 节点**（Nginx2 / 微服务4 / Redis3 / Kafka3 / ES3 / MinIO+File4 / MySQL2 / MongoDB3 / HDP2），**不是**标准版的共置 17 节点。HDP 节点即 Flink 节点。数据库仍为 MGR+Router / 副本集 / 哨兵。按各组件独立 IP 逐项填写；资源清单与架构图按独立节点拓扑出。详见 constraints.md B。

> 精简版（集群精简版）：**6 节点**拓扑，**不填场景 A/B**（精简版无此维度）。缺省 IP：Nginx 192.168.1.20；微服务 192.168.1.21/.22；中间件 192.168.1.51；数据库 192.168.1.31；HDP/Flink 192.168.1.30；域名 hap.domain.com。数据库为 MySQL/MongoDB/Redis 单节点共置，K8s 1主1从。详见 reference/streamlined-vs-cluster.md。
