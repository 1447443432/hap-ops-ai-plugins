# 结构化输入格式

用户可以直接提供一条或多条记录，每条记录使用以下字段：

```text
软件包身份：Docker
名称：Docker
版本：29.9.3
架构：X86_64/AMD64
HAP地址：https://pdpublic.mingdao.com/private-deployment/offline/common/docker-29.9.3.tgz
源地址：
备注：
```

多条记录之间空一行。架构只能填写明确值，例如 `X86_64/AMD64` 或 `ARM64/AARCH64`；不能填写“都支持”而不拆成两条记录。

来源为官方文档时，应将页面中的每一个软件包和架构分组转换为独立记录，并在变更清单中展示完整地址。若软件包身份无法确认，不得只根据名称或 URL 文件名自动合并。

字段别名可以按以下方式识别，但必须以目标表实际字段结构为准：

- 软件包名称：`名称`、`软件包名称`
- HAP 地址：`HAP地址`、`HAP下载地址`
- 源地址：`源地址`、`源下载地址`
- 备注：`备注`、`说明`

地址字段必须保存完整原始 URL，不转换为 Markdown 超链接。地址缺失、截断或无法判断是 HAP 地址还是源地址时，先暂停并补充信息。
