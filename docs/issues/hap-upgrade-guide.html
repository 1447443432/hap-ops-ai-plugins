单机固定区域被扩写且 HTML 未同步

发现时间：2026-11-24（具体时间未知，Asia/Shanghai）｜记录时间：2026-11-24｜最后更新时间：2026-11-24

环境与表现

  • 涉及文档：v7.3.4 → v7.5.6，单机，AMD64，离线。
  • “5. 检查资源”中出现了用户要求删除的离线核验项、现场信息清单和额外结尾提示。
  • 升级步骤中额外出现通用注意事项、离线资源核验、Compose 文件核对、回退原则、验证记录、变量清单和版本路径说明等非模板章节。
  • MongoDB 预置数据更新命令后出现未经用户要求的补充段落。
  • Markdown 已删改后，HTML 仍残留旧章节，导致两种格式内容不一致。

已确认原因

  • 生成时在固定模板之外加入了扩展说明。
  • Markdown 删除后没有通过统一交付流程重建 HTML；手工同步不完整，留下目录与正文残留。
  • 最终校验器的最小字符数门槛阻止了精简后的 Markdown 通过，但此前流程没有以模板完整性作为唯一标准妥善处理，最终造成格式输出不一致。

处理与防复发约束

  • 单机检查资源区域按用户确认收敛：只保留磁盘空间检查项；其他删除项不得被模型补回。
  • 禁止擅自增加不在固定模板中的升级说明小节或操作后的解释段落。
  • 删除 MongoDB 预置数据命令后的附加解释，保留官方操作说明和实际命令。
  • 用户指出 HTML 残留时，以修正后的 Markdown 为准重新生成整份 HTML；不能只改 Markdown 或仅删除 HTML 正文而遗漏目录。

涉及文件

  • 升级文档/HAP升级指南-v7.3.4-to-v7.5.6-单机-amd64.md
  • 升级文档/HAP升级指南-v7.3.4-to-v7.5.6-单机-amd64.html
  • plugins/hap-ops-ai-plugins/skills/hap-upgrade-guide/SKILL.md

解决结果

  • 已从 Markdown 删除“5. 检查资源”中除磁盘空间外的框选内容。
  • 已删除 MongoDB 预置数据命令之后的额外解释段落。
  • 已从 Markdown 删除扩展注意事项、离线资源核验、Compose 核对、回退原则、验证记录、变量清单和版本路径等模板外章节。
  • 因标准交付校验器的字符长度门槛未接受精简后的文档，使用项目 HTML 转换器根据修正后的 Markdown 重建 HTML；重建后检查旧章节与标题均不再出现在 HTML 中。
  • 后续规则已在升级 Skill 中明确：固定区域不扩写，模板外小节不生成；Markdown 改动后必须重建 HTML 并核对目录和正文。

验证状态：本次截图涉及内容已从 Markdown 和重新生成的 HTML 中移除，单机文档两种格式已同步。标准最终校验器因文档长度门槛未通过；HTML 由项目转换器重新生成。
